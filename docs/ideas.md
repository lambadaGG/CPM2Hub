# GearMarket — идеи и роадмап

> Сохранено из обсуждения 2026-08-15. Обновлять по мере реализации.

## 1. Дешёвый/бесплатный товар-«затравка» (вовлечение)

Сейчас минимальная цена — 1⭐ (Nick Pack). Нужен дешёвый/бесплатный вход.

- **«Цвет дня» / бесплатный livery-код** — раз в день бесплатно (удержание, ежедневный заход)
- **Базовый набор ливрей под топ-модели** (R34, Supra, M5, Lambo) — 5–15⭐. Самый ходовой товар по соцсетям; сейчас в маркете один пример винила
- **Стартовый пак для новичка** (гараж + звук + номер) со скидкой

## 2. Новые категории товаров в маркете

- **Пресеты подвески/дрифта** (углы, занижение, жёсткость) — отдельно от коробки передач
- **Звуки двигателя / выхлопа** (turbo, V8 burble) — частый запрос комьюнити
- **Номерные знаки / плашки** (кастомные таблички)
- **Ливреи спецтехники**: полиция, такси, скорая — в игре есть эти режимы
- **Дым для дрифта, неон, свет фар** (цветовые пресеты)
- **Наклейки/декали** отдельно от полной обёртки (стикер-паки)
- **Готовые билды персонажа** (одежда / анимации / эмодзи)

## 3. Функции / инструменты

- **Библиотека готовых кодов по модели авто** — поиск/фильтр «выбери свою машину → готовые ливреи под неё» (сейчас только генератор цвета с нуля)
- **Рейтинг/голосование за пресеты** — топ-лист «лучший сетап для X»
- **Калькулятор подвески** (углы развала, занижение) — в паре с калькулятором коробки
- **Сравнение машин / характеристик** — таблица разгона, макс. скорость
- **Wishlist/избранное** — сохранять понравившиеся пресеты
- **Реферальная программа** — звёзды за приглашённых друзей (виральность)
- **Ежедневный бонус звёзд / streak-система** — геймификация захода
- **Уведомления о новых пресетах** — по подписке / любимой модели
- **Интеграция с гайдами** — ссылки TikTok/YouTube из карточки товара
- **Мультиязычность** — аудитория международная (ID, MY, TR, TL); русский интерфейс сузит охват

## 4. Расширение «Эскроу»

Сейчас эскроу — только покупки в хабе. Прокачать до полноценной безопасной площадки для сделок между игроками:
машины, аккаунты, валюта игры. Прямые сделки в мобильных играх = много скама → это больная тема.

## 5. Структура подписки PRO (смета под новые фичи)

### Тарифы

| План | Цена | Фичи |
|---|---|---|
| Free | 0 | Базовые инструменты, 1 бесплатный «Цвет дня», лимит скачиваний (напр. 3/мес), эскроу 5% |
| PRO месяц | ~149⭐/мес | Безлимит скачиваний, 0% комиссия эскроу, ранний доступ к новым фичам, рейтинг-премиум |
| PRO год | ~1490⭐/год (−20% = 1192⭐) | Всё из месяца + эксклюзивные пресеты, приоритетная поддержка |

### Что даёт PRO под новые фичи
- Безлимит: библиотека кодов по моделям, wishlist-лимиты
- Ранний доступ: калькулятор подвески, сравнение машин, фильтры по модели
- Рейтинг-премиум: метка «PRO» на своих пресетах, повышенный виз в топ-листе
- Эскроу 0% — стимул держать подписку при активных сделках

### Рекомендуемая очерёдность реализации
1. «Цвет дня» + базовые ливреи 5–15⭐ (быстрый виральный вход)
2. Новые категории (подвеска, звуки, номера, спецтехника, декали)
3. Мультиязычность (расширение охвата)
4. Калькулятор подвески + библиотека кодов по моделям
5. Рейтинги, wishlist, рефералка, streak
6. Расширение эскроу на P2P-сделки
7. Подписка PRO (после накопления фич, иначе нечем мотивировать)
